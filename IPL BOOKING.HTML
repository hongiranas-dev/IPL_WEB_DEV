Guidelines

Ticket Verification

Show the QR code from your e-ticket at the stadium gate. Each code can be scanned only once, so please don't share it.

ID Proof Requirement

Carry a valid government photo ID (Aadhaar, Driving Licence or Passport). The name on the ID must match the name on the ticket.

Prohibited Items

Outside food and drinks, sharp objects, lighters, large bags and professional cameras are not allowed inside the stadium.
